One line roasting an alarm clock that rings at 6 AM on a Saturday — told by the snooze button itself, which has had enough of being slapped like a vending machine that ate your last dollar.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
# writes /output/entry.txt (single line, 110 chars)
```

The program self-checks before writing: the entry must be a single line of 1–200 characters, with no leading/trailing whitespace, no double spaces, and it must name the 6 AM Saturday alarm. If any check fails, it throws instead of writing.
